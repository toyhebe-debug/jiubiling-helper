# 九比灵小助手
家庭备货与产检随手记。GitHub Pages 提供页面，Cloudflare Worker 和 D1 保存家庭共用记录。无需 ChatGPT 登录。

## 使用
首次由管理员通过一次性设置链接设置家庭密码。家人打开普通网址，输入相同密码即可进入；登录状态保留 90 天。补货、产检问题和医生答复在两台设备间共享。提醒显示在首页。

## 数据与访问
公开仓库不包含家庭记录、密码或登录令牌。密码在服务端经加盐 PBKDF2 处理，登录会话采用随机令牌且数据库仅保存其哈希。登录尝试有限流，所有家庭记录接口都检查登录。写入带版本号，避免并发覆盖。

## 开发与部署
- `npm ci` 安装依赖，`npm run dev` 启动前端，`npm run dev:api` 启动本机接口。
- `npm run build` 生成 `docs/`；生产构建设置 `VITE_API_BASE` 和 `VITE_BASE_PATH`。
- `wrangler.jsonc` 为本机开发模板。生产配置保存在未跟踪的 `wrangler.deploy.json`。
- `migrations/` 只包含数据库结构；数据迁移文件和私密备份存于忽略目录 `.private/`。
- 初次设置使用 Cloudflare secret `BOOTSTRAP_HASH`。设置完成后接口自动关闭，可移除该 secret。
- 更换密码或丢失全部登录信息时，由账号所有者在部署端处理恢复，不能通过公开网页绕过验证。
